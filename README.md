# Chiru

An AI-powered modern web application focused on developer productivity, automation, and scalable user experiences.

## Features

- Modern responsive UI
- AI-powered workflows
- API integrations
- Secure and scalable architecture
- Fast performance optimization
- Dark/Light mode support
- Mobile-friendly design

## Tech Stack

- JavaScript / TypeScript
- React / Next.js
- Tailwind CSS
- Node.js
- REST APIs

## Installation

```bash
git clone https://github.com/Chiranthan-M/Chiru.git
cd Chiru
npm install
npm run dev
```

## Goals

This project aims to help developers build smarter applications using modern AI integrations and clean development practices.
